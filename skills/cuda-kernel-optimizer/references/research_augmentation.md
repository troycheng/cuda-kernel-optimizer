# 外部检索与质证

外部资料用于确认当前社区能力、核实版本敏感的机制事实和挑战既有判断。它不属于确定性执行工具，也不能替代本地精度与性能证据。研究按具体决策触发。已有核验的版本、生产边界和技术前提仍适用时，直接引用结论；只研究变化或尚未解决的部分。

## 触发条件

- 准备新增非平凡 kernel、通信 primitive 或通用框架接入，需要确认应当复用、backport、窄适配还是独立实现；
- 技术栈新颖或版本敏感，内置知识为空或关键源码能力未知，且准备实施昂贵候选；
- 两个方向都有合理解释，现有证据不足以取舍；
- 连续候选没有收益，需要检查遗漏的机制或 subsystem；
- 局部机制收益与完整 workload 结果冲突，准备关闭仍有较高 primary ROI 的候选；
- 准备形成 Target 的 terminal reason，但最高价值的剩余方向仍有关键知识或因果缺口。

普通参数调整、已有实现测量、benchmark harness 和诊断脚本不必逐一检索或进行多方质证。当前源码和本地证据已经决定机制结论，或一个更便宜的实验能更快证伪时，跳过机制研究；但局部实验不能证明社区不存在等价能力，不能代替已经触发的社区能力核验。触发后先声明总等待上限；不可用或超时只记录，不阻塞本地工作。

## 社区能力核验

先检查当前部署版本的源码、已安装组件和依赖；外部来源可访问时，再定向检查官方上游源码、release、已合并及在途 PR/Issue。Triton Index、Meta TritonBench 等维护型目录可以帮助发现候选实现，但目录条目、搜索摘要和社区排名不能直接证明当前版本可用；最终事实要回到拥有该能力的源码、release 或变更记录。

核验必须区分三个层次：

1. 底层 kernel、算法或通信 primitive 是否存在；
2. 目标框架及当前版本是否已经接入；
3. 当前 production replacement boundary 是否已有可用的正确性和端到端证据。

核验只做到足以决定当前工作属于复用、最小 backport、窄适配、测量 harness 还是独立实现。研究增量简要说明已核验的版本与范围、三个层次各自的状态、对当前实现边界的影响，以及仍未核实的内容；不另建能力数据库。只有确实改变 Candidate 设计或实验前提的版本化事实，才作为现有 Experiment 的 `material_premises` 保存。

外部优化器或代码生成项目只是候选实现来源。其输出按普通 Candidate Variant 冻结，并接受相同的精度、成对性能和真实 workload 验证；外部项目的 benchmark、排名或论文结果不给候选增加可信等级。

## 机制与一手资料核验

1. 当前版本的官方文档、release note、源码和研究论文；
2. 维护活跃的参考实现与公开问题记录；

核对版本、架构、编译路径和运行条件，只把来源直接支持的内容记为事实。论文中的搜索策略、性能模型或优化抽象可以帮助 ChatGPT 组织假设，但不成为自动候选生成、晋级或停止规则。研究结束时写出简短研究增量：新确认或推翻了什么、适用于哪个版本、如何改变候选排序、拒绝范围或实验设计。资料堆积、搜索次数和未改变决定的通用背景不算研究成果。

## 异构 AI 质证

外部 AI 只用于提出反例、遗漏方向和检索线索。触发高成本候选、高潜机制关闭或 Target 终止的质证时，至少尝试一个可用的非 OpenAI 模型家族；ChatGPT Pro、Codex 和 OpenAI 子智能体属于同一模型家族，不构成异构质证。同一提供方或模型家族的不同入口也不算独立来源。存在重大未解决分歧时才增加第二个独立家族，不按固定供应商列表轮询，也不做多数投票。

## 提问内容

发送最小充分材料：目标身份、已确认事实、竞争性假设、主要不确定性、候选机制、最低有效收益和已有反例。私有代码、数据、地址、账号和未公开业务指标必须去除或抽象化。

向各模型发送同一份封闭材料，并要求分别给出：

- 支持与反对该方向的理由；
- 最低成本证伪；
- 可能混淆测量的因素；
- 需要核实的一手来源；
- 在什么证据下应停止。

准备关闭高潜候选时，额外要求对方解释当前失败最多否定实现、集成还是机制，以及哪个不同的最低成本实验最能改变结论。保留完整回答、模型家族、失败来源和总等待时间；不要将“已发送问题”记录为“已完成审查”。ChatGPT 对意见去重，明确哪些内容是来源事实、哪些只是推断，并记录分歧是否改变了拒绝范围或下一实验。最终候选是否成立，以当前 Target 上的本地精度和测量为准。

外网或异构模型不可用时，使用当前部署源码、内置知识、已有 profiler 事实和可重复实验继续工作，并在结论中说明未完成项、社区能力核验范围、知识时效边界和独立质证强度；不能把未核实内容表述为当前事实，也不能因没有检索结果就判定不存在可行方向。
